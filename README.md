# 二十四節気と七十二候の日時計

GitHub Pagesで公開できる、静的な暦盤Webアプリです。スマホやPCのブラウザでURLを開くだけで、現在の二十四節気・七十二候・次の切り替えまでの残り時間を確認できます。

## 使い方

1. このフォルダをGitHubリポジトリに入れます。
2. GitHubの `Settings` → `Pages` で公開元を選びます。
3. 発行されたURLを開きます。

ビルド作業、サーバー、外部API、ユーザー登録は不要です。

## ファイル構成

- `index.html`: 画面の骨組み
- `styles.css`: 和紙・真鍮・墨色を基調にした見た目
- `app.js`: 時計盤の描画、言語切り替え、日付操作
- `data/season-2026.json`: 2026年の二十四節気・七十二候データ

## 対応年

初期版の対応年は **2026年のみ** です。

対応範囲外の年では推測値を出さず、「対応範囲外」と表示します。年を追加する場合は `data/season-2027.json` のようなファイルを追加し、`app.js` の `SUPPORTED_YEARS` に年を追加してください。

## データについて

- 二十四節気の切り替え時刻は、国立天文台 暦計算室の2026年データを元に、JST（日本標準時）で保存しています。
- 七十二候は2026年の暦資料の日付境界を元に、各日の `00:00 JST` を切り替え時刻として保存しています。
- 各二十四節気の初候は、節入り時刻に合わせています。

参考:

- 国立天文台 暦計算室「二十四節気・雑節」
- 暦注カレンダー系の2026年七十二候一覧

## 主な機能

- 現在日時の表示
- 現在の二十四節気と七十二候の表示
- 次の節気・候までの残り時間
- 日時計風の円形UI
- 現在時刻に合わせて回る針
- 外周の二十四節気リング
- 内側の七十二候リング
- 現在の節気・候の強調表示
- 前日・翌日・今日に戻る操作
- 時計盤の手動回転
- 日本語 / Deutsch 切り替え
- 選択言語の `localStorage` 保存

## 対応ブラウザ

- iPhone Safari
- Android Chrome
- PC Chrome

HTML / CSS / JavaScriptだけで動くため、GitHub Pagesでそのまま公開できます。
